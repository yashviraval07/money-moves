# Money Moves

Money Moves is an interactive financial literacy demo for younger students in the UAE.
It explains everyday money choices in simple language and lets learners try a small budget plan in UAE dirhams (AED).

## What it contains

- A budget planner for balancing needs, wants, and savings
- A quick three-question quiz with feedback
- Short lessons on needs, wants, saving, and goals
- Rounded UAE dirham examples converted from the original rupee amounts for learning purposes
- A responsive single-page design with no external dependencies

## View it

There is no build step. Download or clone this repository, then open `index.html` in a web browser.

You can also browse the live source on GitHub: [index.html](https://github.com/yashviraval07/money-moves/blob/main/index.html).

## Extend it

Everything is contained in `index.html`, so it is easy to experiment with:

1. Edit the HTML, CSS, or JavaScript in `index.html`.
2. Refresh the file in your browser to see the changes.
3. Add new lessons, quiz questions, or planning ideas as you learn more.

The sample values use a rounded learning conversion based on 1 INR ≈ AED 0.038258, checked on 19 September 2026. They are educational examples, not financial advice.
